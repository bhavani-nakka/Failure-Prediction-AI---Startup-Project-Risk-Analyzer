## 📌 About the Project

Failure Prediction AI – Startup & Project Risk Analyzer is a Python-based application focused on identifying and evaluating potential risks that may affect startups and projects.

The platform considers different business and project-related factors, including market conditions, technical feasibility, financial aspects, and competition. It aims to present meaningful assessment results, highlight potential risks, and provide recommendations through an interactive interface.

The project is developed incrementally through multiple milestones, covering application development, risk assessment, analytics, and report generation.

## ✨ Key Features

- **Project Assessment:** Enter project details and assessment inputs.
- **Risk Identification:** Evaluate different risk categories.
- **Success Probability:** Display an estimated success probability based on assessment inputs.
- **Risk Analytics:** Explore assessment results through visualizations.
- **Key Findings:** Highlight important observations.
- **Recommendations:** Present suggestions to address identified risks.
- **Assessment Reports:** Generate downloadable PDF and TXT reports.
- **Interactive Interface:** Navigate through assessment pages and dashboards.

## ⚙️ Installation and Setup

### Clone the repository

```bash
git clone https://github.com/bhavani-nakka/Prediction-Ai.git
```

### Navigate to the project

```bash
cd Prediction-Ai
```

### Install dependencies

Navigate to the relevant milestone folder and install its requirements:

```bash
pip install -r requirements.txt
```

### Run the application

Run the appropriate application entry point for the milestone you want to explore.

Refer to the individual milestone folders for their specific setup instructions.
